# Some Other Python Practices

This repository contains some small Python programs and exercises I wrote while learning Python.

## Goldbach Partition

`goldbach_partition.py` explores Goldbach-type partitions of integers.

- For even integers, it searches for a representation as the sum of two prime numbers.
- For odd integers, it searches for a representation as the sum of three prime numbers under additional constraints.

## Requirements

- Python 3
- No external libraries are required.
